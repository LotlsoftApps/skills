# meta description

Compiled 2026-08-14. Every claim carries the date its quote was true; search engines change their documentation without announcing it.

## Summary

Written from the claims below and checked against them.

Google does not use meta descriptions as a ranking signal, and it rewrites them into the displayed snippet roughly two-thirds of the time regardless of length. A compelling, unique description can still improve click-through and traffic when it appears, and it matters for Googlebot. There is no technical character limit, but visible snippets are truncated to fit the device, typically displaying around 155 characters on desktop and under 120 on mobile.
